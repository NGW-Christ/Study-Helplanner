# 🎓 StudyHelplanner - Premium AI Study Suite

StudyHelplanner is a high-performance, AI-driven study platform designed to transform raw notes into structured learning materials. Built with a focus on premium aesthetics and seamless user experience.

![Premium UI](https://github.com/user-attachments/assets/0aa67016-6eaf-458a-adb2-6e31a0763ed6)

## ✨ Key Features

- **🤖 AI-Powered Generation**: Convert PDFs, images, or text into structured Flashcards, Quizzes, and Summaries using Google Gemini.
- **💎 Premium UX**: Smooth staggered animations, glassmorphism interfaces, and a refined brand identity.
- **📱 Mobile Optimized**: Zero horizontal scroll, fluid text wrapping, and touch-optimized interactive components.
- **⚡ Real-time Sync**: Instant data persistence with Supabase.
- **🎯 Focus Mode**: Distraction-free study environment to boost productivity.
- **📊 Interactive Learning**: 
  - **Flashcards**: Flip-card interface with deep-dive AI explanations.
  - **Quizzes**: Real-time feedback with detailed rationales for every answer.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS (Custom Brand Theme)
- **Database/Auth**: Supabase
- **AI Engine**: Google Generative AI (Gemini Pro)
- **Icons**: Lucide React

## 🚀 Getting Started

1. **Clone & Install**:
   ```bash
   git clone https://github.com/your-username/StudyHelplanner.git
   npm install
   ```

2. **Environment Setup**:
   Create a `.env.local` file:
   ```env
   VITE_SUPABASE_URL=your_url
   VITE_SUPABASE_ANON_KEY=your_key
   GEMINI_API_KEY=your_gemini_key
   ```

3. **Run**:
   ```bash
   npm run dev
   ```
